## 命名与维护约定

- **命名**：采用「类别-主题」形式（如 `资源加载-落地计划`），类别目前有 `AB框架` / `资源加载` / `Lua热更` / `构建与热更` / `战斗关卡`。
- **归档**：文档的"待实现/待修复"项全部清零后，移入 `Finish/`，并在上方表格补一行原因。
- **交叉引用**：文档之间用**裸文件名**互引即可（同目录）；引用 `Finish/` 里的文档要带 `Finish/` 前缀。
- **只写结论不改代码的调研**：归到对应类别的「设计」文档或单独成文，完成后同样归档。
