config 文件夹是 MiniTemplate（Luban 配表）

导表：
  双击 Config/Config/gen.bat 或 ConfigTools/gen_code_json.bat

Unity 运行时依赖（导表后若报 CS0246 Luban / SimpleJSON）：
  已放在 CarrotFantasy/Assets/Scripts/LubanLib/
  勿删除；重新拉代码后若缺失请从仓库恢复该目录。

导出位置：
  代码 -> CarrotFantasy/Assets/Scripts/Config/Luban/
  数据 -> CarrotFantasy/Assets/Game/Config/Luban/（打进 config/luban AB 包，支持热更）

已接入 Luban 的数据表：
  Tower.xlsx / Monster.xlsx / Bullet.xlsx / Buff.xlsx / Item.xlsx

关卡刷怪配表（CSV，非 Luban）：
  ConfigTools/LevelSpawn/*.csv
  Unity 菜单：CarrotFantasy -> 关卡刷怪表 -> 导入 ConfigTools/LevelSpawn 下全部 CSV
  导入后写入 CarrotFantasy/Assets/Game/Json/Level 与 StreamingAssets 同名关卡 JSON 的 roundInfo

战斗 combat 流程（Tick 顺序、索敌、子弹、碰撞、空间网格）：
  CarrotFantasy/Assets/Scripts/Model_Battle/BattleCombatFlow.md
